# Scientific and release limitations

- All 88 choices have functional pathways under explicit compatible inputs.
  Only three retain original reference profiles. The 85 newer profiles are
  predominantly transferred/hypothetical and not independently field validated.
- Scallion, Brachiaria and ryegrass require named subtypes. Perennial initial
  age alone cannot create mature structure; actual organ stocks are required.
- Original layer-water and rotation-effect models failed important simple
  baselines. The rejected V1.1 candidate remains unpromoted. No current API
  scenario becomes a validated optimal rotation or calibrated forecast.
- Living effects can be large under hypothetical stocks/rates. They are not
  observed local pest/microbial abundance or measured causal yield effects.
- Paddy redox/N and daily CAM pathways are reduced experimental approximations;
  unsupported detailed chemistry/physiology remains unavailable.
- Dry product cannot become fresh/processed sale mass without supplied valid
  conversion. Cacao pods, coconut whole fruits and rough rice retain identities.
- Prices/costs/access are conditional supplied inputs. Automatic regional
  benchmark adoption is not implemented in the release API. Existing research
  adapters/data are preserved; incomplete economics remains unavailable.
- NASA POWER is available only from a compatible operator-configured cache;
  reference replays are historical scenarios, not future forecasts. No other
  satellite source is claimed as an integrated release input without execution.
- One-host, one-process queue; no multi-tenant ownership isolation, distributed
  workers or authentication accounts. Shared bearer mode is not sufficient for
  public multi-user deployment. Add gateway authz/rate limits/TLS/quotas.
- Docker is optional and is not verified when no Docker engine is available.
  Full scientific regression requires the preserved local research archive.
- Public distribution requires the owner's code-license and source-rights
  review. No license, push, deployment or history rewrite is performed.
